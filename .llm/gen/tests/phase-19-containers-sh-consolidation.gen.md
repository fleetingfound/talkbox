# Tests: Phase 19 consolidation of repeated container logic in `lib/containers.sh`

Linked plan: [phase-19-containers-sh-consolidation.gen.md](../plans/phase-19-containers-sh-consolidation.gen.md)

Summary: the plan consolidates twelve duplicated function families in [lib/containers.sh](../../../lib/containers.sh) behind unified cores while preserving the fifteen `run_*` executors as the dispatch surface, so the unit tests are revised — before touching the implementation — to pin the podman command construction through those executors with a logging podman shim, replacing the plan-level tests of the internal interfaces the refactor drops; every revised and new test passes against the current, unmodified implementation.

## New tests

All new tests drive the surviving `run_*` executors with the shared logging podman shim and assert on the logged podman command lines (token membership within a command, ordering within a command via token positions, and ordering between commands via log line numbers). The shim and assertion helpers live in [test/unit/helpers.bash](../../../test/unit/helpers.bash): `make_podman_shim` writes a generic podman mock driven by `PODMAN_*` environment variables (existing containers/volumes/images, `inspect` outcomes, `ps` ancestor/external listings, and a fail pattern with exit code), `podman_line`/`podman_line_no`/`podman_count`/`podman_create_line` query the invocation log, and `line_has_token`/`line_lacks_token`/`line_token_at` perform token-level assertions on a logged command line.

- `test/unit/containers.bats` — sixteen `run_onbox` tests pinning the create-args construction (workdir, userns, cap drops, the pasta network string with and without `-T` ports, read mounts read-only, write mounts as bind-mounts, the read-write host worktree bind-mount, global/project dotfiles and art mounts and their absence gating, container name, base image, `sleep infinity`, `--init` and its position ahead of the image, interactive `--interactive`/`--tty` gating, git-mount gating with the eager gitdir `volume create`, git-identity and prompt `--env` vars, GPU options, the absence of `--rm`/`--tmpfs`/`/run/talkbox`, and the absence of any base-image probe) plus the exec/stop tail (interactive `/bin/bash` for an empty command, `bash -c` with the exec's exit status propagated, best-effort `stop` succeeding even when it fails).
- `test/unit/netbox-offbox.bats` — eighteen `run_netbox`/`run_offbox` tests pinning the sandbox create paths: worktree-volume mounts and container names, per-type pasta suffixes (DNS-forward for netbox, `-i,lo,-I,talkbox0` for offbox) with `-T` ports, read-only read mounts and write mounts as named volumes with their populate `podman run` commands, GPU/`--init`/prompt-env/dotfiles/no-tmpfs create args, git-mount and git-identity gating, commit source selection (netbox commits onbox; offbox commits netbox, else onbox, else base), `TALKBOX_FRESH` skipping the commit, `TALKBOX_INHERIT` selecting the commit source, and the offbox populate falling back per volume between the netbox volumes and the host.
- `test/unit/lifecycle.bats` — sixteen executor tests pinning the lifecycle verb command sequences: onbox `run_recontain`/`run_rebuild` (rm → volume rm → [volume create] → create → start → stop, build first on rebuild, and no nft, setup exec, user command or image probe even with a non-empty deny set), sandbox recontain/rebuild for netbox and offbox (commit-before-rm, build first on rebuild, volume rm/populate-run/volume-create chains, setup exec, and the base-source probe with `ensure_base_image` building only when the base image is missing), and the rm verbs (onbox removing only the gitdir volume, netbox/offbox removing worktree/gitdir/write volumes with the root-image `rmi` only when `podman image exists` succeeds, volume removal guarded by volume existence, and the `run_rm_image`/`run_netbox_rm_image`/`run_offbox_rm_image` in-use refusal with no `rmi` emitted).

## Tests edited

- `test/unit/netbox-offbox.bats` — `netbox plan adds the git mounts and the populate leaves the gitdir volume empty` and `offbox plan adds the git mounts and the populate leaves the gitdir volume empty` are re-expressed as `netbox populate copies the worktree and write mounts from the host but never touches the gitdir volume` and `offbox populate copies from the host when the root source is base and never touches the gitdir volume`: they keep the `plan_netbox_populate`/`plan_offbox_populate` assertions (pinning the preserved signatures and the gitdir-volume policy) while their create-args assertions moved to the new `run_netbox`/`run_offbox` executor tests, as the plan requires.
- `test/unit/helpers.bash` — gained the shared shim and log/token helpers described above; no existing helper changed.
- `setup()` in the three revised files gains the shim/log paths and the empty `DENY`/`ALLOW` (and `SRCS`/`DSTS`) arrays the executor namerefs consume, plus a `use_podman_shim` helper; unused plan-level helper functions whose only callers were the superseded tests were removed (`array_contains`/`array_has`/`plan_subcommands` in `containers.bats`, `array_has` in `netbox-offbox.bats`, `array_contains`/`array_has_none`/`plan_has_subcommand`/`plan_volume_rm_tokens` in `lifecycle.bats`).

## Tests removed

All removed tests invoke internal interfaces which the plan drops ("their only remaining references are the superseded unit tests listed below") and are replaced one-for-one in coverage by the executor-level tests above; the plan's [tests](../plans/phase-19-containers-sh-consolidation.gen.md) section identifies each group as "Superseded and removed".

- `test/unit/containers.bats` — the 30 onbox plan-level tests invoking `plan_onbox`, `plan_recontain` or `plan_rebuild` directly (workdir/userns/caps/pasta/worktree/dotfiles/GPU/`--init`/name/`--rm`/ports/mounts/interactive/git-mounts/git-identity/prompt-env/tmpfs assertions and the recontain/rebuild propagations). Plan: "the 30 onbox plan-level tests — every test invoking `plan_onbox`, `plan_recontain` or `plan_rebuild` directly".
- `test/unit/netbox-offbox.bats` — the 33 netbox/offbox plan-level tests invoking `plan_netbox`, `plan_offbox`, `plan_netbox_recontain`, `plan_offbox_recontain`, `plan_netbox_rebuild` or `plan_offbox_rebuild` directly (worktree/name/network/GPU/ports/write-volume/dotfiles/identity/`--init`/prompt-env/tmpfs create-args and their recontain/rebuild propagations). Plan: "the 33 netbox/offbox plan-level tests — every test invoking `plan_netbox`, `plan_offbox`, `plan_netbox_recontain`, `plan_offbox_recontain`, `plan_netbox_rebuild` or `plan_offbox_rebuild` directly".
- `test/unit/lifecycle.bats` — the 19 lifecycle plan-level tests invoking `plan_recontain`, `plan_rebuild`, `plan_rm_container`, `plan_rm_image`, `plan_netbox_recontain`, `plan_offbox_recontain`, `plan_netbox_rebuild`, `plan_offbox_rebuild`, `plan_netbox_rm_container`, `plan_offbox_rm_container` or `plan_netbox_rm_image` directly, including the two pinning the vestigial `in_use` parameter of `plan_rm_image`. Plan: "the 19 lifecycle plan-level tests — every test invoking `plan_recontain`, `plan_rebuild`, `plan_rm_container`, `plan_rm_image`, `plan_netbox_recontain`, `plan_offbox_recontain`, `plan_netbox_rebuild`, `plan_offbox_rebuild`, `plan_netbox_rm_container`, `plan_offbox_rm_container` or `plan_netbox_rm_image` directly, including the two that pin the vestigial `in_use` parameter of `plan_rm_image`".

Retained unchanged: the `run_onbox`, `run_netbox`, `run_offbox`, `run_netbox_recontain`, `run_offbox_recontain`, `run_netbox_rebuild`, `run_offbox_rebuild` and `run_*_rm_image` podman-shim tests; the `inherit_source`, `plan_volume_populate` and `plan_volume_rm` tests; the `prune_external_image_containers` tests; and all of `test/unit/git-transport.bats`.

No end-to-end tests were added or changed; `make test-unit` (247/247), `make test-e2e` (76/76), `make lint` and `make format` all pass with the tests in place, against the unmodified implementation.
